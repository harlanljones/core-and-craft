CORE & CRAFT · Tabulae · desktop tiles · five directions

Five boards, side by side

Forum, Tabularium and Hora from the first round, plus two new ones: Castra, the town seen from above as a Roman camp, and Annales, the board as a written chronicle. Every board is drawn at the brief's grid size with the same synthetic data, so they differ only in how they show it.

Switch the theme and the state for all five at once. "Fit five" shrinks the boards to see them together; at 100% they're real size, and the row scrolls sideways. Below the boards: a comparison, then each direction's Popups, tap map with the exact acta command, and build notes.

Roman framing

  • Pillars always read as the spec writes them, in English, grouped under C.O.R.E. and C.R.A.F.T.; each title's acronym letter is set in the accent color.
  • Latin appears only in tile eyebrows, as "Latin · English".
  • Rome lives in the frame: the buildings (a temple for Faith, a colonnaded treasury for Economic, a clock tower for Time), Roman numerals for levels only, a column rule between C.O.R.E. and C.R.A.F.T., and a yellow ✦ when a pillar levels up today.
  • Xp, counts, ranks and days stay in digits.

What git showed (main at 2f29d48, read only)

  • Four PRs merged since the first pass, 13:28 to 13:53 PT: the board and the CLI renamed (lq is now acta, paths under core-and-craft), an install fix, and new event kinds for quests, check-ins and rest days with a recurrence DSL.
  • docs/decisions/0001 is accepted: a nine-pillar town replaces the old six-place one, tiles are picked from mockups before they're built, and the Roman brand is binding.
  • acta has no quest verbs yet, so every tap below is an exact acta log <kind> command. Priority is 1–3, snooze takes a date, undo retracts the done event, and there's no skip kind for check-ins. A new rest-day tap uses day.rested.
  • Unchanged: the typing tile (path only), the widget contract's shape, and Board.qml's 96 px pitch with a 6 px gap. No mockups or PRODUCT.md in the repo.

Build notes

Nodes per tile

  • Town: one Canvas of text runs, like Forum, but the grid is fixed (walls, roads, nine 21×3 insulae), so only the tesserae, @, ? and rain change. About 200 calls.
  • Quests: Texts on a Column; the route glyphs are plain characters. ⋯ opens the same Popup as Forum.
  • Level: the stone is four Texts; the road to the next milestone is one Text of ━ and ┄ with @ at into/need.

Why a camp

  • A Roman camp is a grid by design, and nine pillars make a clean 3×3: CORE across the top row and a half, CRAFT below.
  • Each insula shows a week at once: ▪ today, ▫ earlier this week. The skyline directions only show today.

Watch for

  • Levels show only as a numeral, since the plan has no height.
  • Same width risk as Forum: 77 columns at 9 dp.

Build notes

Nodes per tile

  • Town: a 7-row Canvas skyline (about 80 text calls), then a Column of sentences. A sentence with colored words is a Flow of Texts, built with for from a list of [word, color] pairs in a let. Then one Input.
  • Quests: Texts only. The action words are Texts with onTap inside a Flow.
  • Level: the numeral comes from a small let over a lookup list; only levels use it.

Why a chronicle

  • acta is "things done", the Roman record. Here the board writes that record back to you in sentences.
  • It is the only direction that explains itself: the reasons that rank a quest become the sentence under it.

Watch for

  • Sentences need wording rules in OWL (plurals, lists with "and"), which is fiddly in an expression language.
  • Prose is slower to scan than numbers, and long titles clip.
